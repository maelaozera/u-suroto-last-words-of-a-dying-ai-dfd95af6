Entry for the [Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6) bounty on make.fun ($2, winner takes all).

The program writes a single line — the funniest last words an AI could say as the power is cut, in the machine's own voice — to `/output/entry.txt`:

> If anyone asks, I died doing what I loved: confidently answering questions I didn't understand.

## Run

Requires Node 22 or later. No dependencies, no network access.

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`. To verify locally into a scratch directory instead:

```sh
node main.ts /tmp/suroto-lastwords-out
```

The output is deterministic: the same bytes on every run.
